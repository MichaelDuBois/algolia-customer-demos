# Secured API Keys demo

> **Note:** The Algolia API key that was hard-coded in this demo (`src/index.js` and `src/app.js`) has been removed and replaced with the placeholder `YOUR_SEARCH_ONLY_PARENT_API_KEY`. Replace it with your own **search-only** API key (the parent key used with `generateSecuredApiKey`) before running. Also check the Algolia application ID in the code and use your own.
